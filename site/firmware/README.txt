Place your web-flashable factory image here and name it:

    tamagotchi-remote.factory.bin

The included manifest currently assumes:
    chipFamily: ESP32-S3
    flash offset: 0

If your device is NOT ESP32-S3, edit ../manifest.json before publishing.

For ESP32-family Web Tools installation, use a factory/merged image suitable for flashing from offset 0. Do not substitute an OTA-only image.
