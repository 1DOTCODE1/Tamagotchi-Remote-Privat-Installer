Tamagotchi Remote

Configure networking, flash the factory firmware, then provision unique credentials directly over USB.

Secrets are generated locally in your browser and are not uploaded by this site.

Device configuration

Enter Wi-Fi details and choose DHCP or a static address before flashing.

Per-device credentials

2

Install factory firmware

Connect the ESP by USB, then install the factory image.

This browser does not support the required Web Serial features.
The installer must be served from a secure HTTPS origin.

When the ESP Web Tools dialog says installation is complete, close it and continue below.
